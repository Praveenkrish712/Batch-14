CSS - Cascading Style Sheet

1) Types of CSS
i - Inline CSS -
ii - Internal CSS
iii - External CSS
Inline > internal > External

2)CSS Syntax
Selector{
    property:value;
}

3) Types of Selector
i - Elements Selector - (h1), (h3), (p)
ii - Class Selector - (.) - Multiple times we can use the same class name
iii - Id Selector - (#) - Unique, Only one time we can Use the same Id name
iv - Universal Selector - (*) - To apply the style in whole site
v - Group Selector - class or id Selector contain different tags wants to the same Style

   4. flex-wrap - nowrap, wrap, wrap-reverse
   5. Align content (Y)(set the height) (Only wrap will enable then only it will act) - start,center, end, space-around,space-evenly, space-between

   7. Flex(on item) - Flex1
