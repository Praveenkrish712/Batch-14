HTML - Hyper Text markup Language

* To create web pages
* Not a Programming Language
* its a markup Language
* Every Website starts with HTML

1) Heading - h1 to h6

2) Paragraph - p

3) hr 

4) br

5) Text formatting - i, b or strong, mark, sub, u and sup

6) Anchor tag (Linking Purpose) - a

7) image tag - img

8) list - Order list and unorder list

9) tables - tr, th and td

10) Forms - input, label, placeholder, required

11) Media Elements - Audio and Video

12) Sematic Tags - header, footer, nav and section


CSS - Cascading Style Sheet

1) Types of CSS
i - Inline CSS -
ii - Internal CSS
iii - External CSS
Inline > internal > External

2)CSS Syntax
Selector{
    property:value;
}

3) Types of Selector
i - Elements Selector - (h1), (h3), (p)
ii - Class Selector - (.) - Multiple times we can use the same class name
iii - Id Selector - (#) - Unique, Only one time we can Use the same Id name
iv - Universal Selector - (*) - To apply the style in whole site
v - Group Selector - class or id Selector contain different tags wants to the same Style
